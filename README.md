# EI2FP: efficient prediction of molecular fingerprints from electron ionization mass spectra

## Overview

The objective of this project is to provide a lightweight and performant neural network model capable of predicting molecular fingerprints (ECFP6 and MACCS keys) from Electron Ionization (EI) mass spectra. The repository contains code for both the Full and Lite architectures of neural networks, notebook with statistics and figures presented in the original publication. These models address the limitations of the DeepEI approach, which uses separate neural networks for each fingerprint, by employing a single multi-output neural network.

## Original publication

Khrisanfov, M. D., Matyushin, D. D., Samokhin, A. S., & Buryak, A. K. (2024). EI2FP: Efficient Prediction of Molecular Fingerprints from Electron Ionization Mass Spectra. , 15(4), 78-185, [https://doi.org/10.5478/MSL.2024.15.4.178](https://doi.org/10.5478/MSL.2024.15.4.178)
